SETUP INSTRUCTIONS (also in README.txt inside the archive):
1. Download and extract sample-data.zip
2. Create directories (needed if Claude Code/Codex not installed):
   mkdir -p ~/.claude/projects
   mkdir -p ~/.codex/sessions
3. Copy the claude/ folder contents to ~/.claude/projects/
4. Copy the codex/ folder contents to ~/.codex/sessions/
5. Launch Contextify
6. Grant permission when prompted for ~/.claude/ access
7. App will detect sample projects (taskflow, weatherly, recipebox)
8. Timeline displays conversations, LLM summaries generate automatically

FEATURES TO TEST:
• Timeline view - shows conversation history with timestamps
• LLM summaries - auto-generated for each conversation
• Quick Search (Cmd+F) - filter current project
• Deep Search (Cmd+Shift+F) - search across all projects
• Project switching - click tabs to switch between projects

The sample data contains synthetic Claude Code and Codex CLI transcript files demonstrating all app features.
