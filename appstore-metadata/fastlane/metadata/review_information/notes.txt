SETUP INSTRUCTIONS:
1. Download and extract sample-data.zip
2. Copy the claude/ folder contents to ~/.claude/projects/
3. Copy the codex/ folder contents to ~/.codex/sessions/
4. Launch Contextify
5. Grant permission when prompted for ~/.claude/ access
6. App will detect sample projects (taskflow, weatherly, recipebox)
7. Timeline displays conversations, LLM summaries generate automatically

FEATURES TO TEST:
• Timeline view - shows conversation history with timestamps
• LLM summaries - auto-generated for each conversation
• Quick Search (Cmd+F) - filter current project
• Deep Search (Cmd+Shift+F) - search across all projects
• Project switching - click tabs to switch between projects

The sample data contains synthetic Claude Code and Codex CLI transcript files demonstrating all app features.
