Contextify keeps a searchable record of every Claude Code and Codex conversation you have.

Watch sessions unfold in real-time. Each message is summarized so you can skim what happened while you were away, or follow along as your AI works.

Search across every conversation you've ever had. Find that one command, that specific fix, or that brilliant solution from weeks ago in seconds.

All processing happens locally using Apple Intelligence. Your transcripts never leave your machine.

FEATURES

• Real-time timeline of Claude Code and Codex sessions
• AI-powered summaries generated on-device
• Full-text search across all conversations
• Automatic project organization
• Support for custom database locations (Dropbox, iCloud Drive)

PRIVACY

Your conversations stay on your Mac. No cloud sync, no analytics, no tracking. Run Little Snitch, block all network requests. The app works exactly the same.

REQUIREMENTS

• macOS 26 (Tahoe) or later
• Apple Intelligence enabled
• Claude Code or Codex CLI installed
