# v1.3.0 Manual QA Checklist

## What Was Released

| Artifact | Channel | Location |
|----------|---------|----------|
| Contextify.dmg | DMG (direct download) | `dist/Contextify.dmg` |
| contextify-arm64.tar.gz | Homebrew (macOS arm64) | GitHub release v1.3.0 |
| contextify-x86_64.tar.gz | Homebrew (macOS x86_64) | GitHub release v1.3.0 |
| Homebrew formula | `peterpym/homebrew-contextify` | GitHub |

## What Changed in v1.3.0

1. `contextify` is the new primary CLI command (was `contextify-query`)
2. `contextify-query` and `contextify-ingest` are now backwards-compatible symlinks
3. `contextify-query` shows deprecation warning in terminals
4. Total Recall skill updated to use `contextify` command
5. CLICoordinator installs unified binary with symlinks

## Environment Preparation

### Sanitize (run before each test section)

```bash
# Quit app
osascript -e 'quit app "Contextify"' 2>/dev/null || true

# Remove app
rm -rf /Applications/Contextify.app

# Remove all CLI binaries
sudo rm -f /usr/local/bin/contextify /usr/local/bin/contextify-query /usr/local/bin/contextify-ingest
rm -f ~/bin/contextify ~/bin/contextify-query ~/bin/contextify-ingest
rm -f ~/.local/bin/contextify ~/.local/bin/contextify-query ~/.local/bin/contextify-ingest

# Remove Homebrew installation
brew uninstall contextify-query 2>/dev/null || true
brew untap peterpym/contextify 2>/dev/null || true
rm -rf "$(brew --cache)/downloads/"*contextify* 2>/dev/null || true

# Remove installed skills
rm -rf ~/.claude/skills/total-recall
rm -rf ~/.codex/skills/total-recall

# Verify clean
which contextify 2>/dev/null && echo "DIRTY" || echo "CLEAN"
which contextify-query 2>/dev/null && echo "DIRTY" || echo "CLEAN"
ls /Applications/Contextify.app 2>/dev/null && echo "DIRTY" || echo "CLEAN"
```

### Database Preservation

The database at `~/Library/Application Support/Contextify/` is intentionally preserved.
If removal is needed:

```bash
BACKUP="$HOME/Desktop/contextify-db-backup-$(date +%Y%m%d-%H%M%S)"
cp -R "$HOME/Library/Application Support/Contextify" "$BACKUP"
echo "Backed up to: $BACKUP"
```

## Section 1: DMG Distribution

### 1A. DMG Gatekeeper and Notarization

```bash
# Verify DMG passes Gatekeeper
spctl -a -t open --context context:primary-signature dist/Contextify.dmg
echo "Exit code: $?"
```
- [ ] Exit code 0 (no output = pass)

```bash
# Verify notarization ticket is stapled
stapler validate dist/Contextify.dmg
```
- [ ] Output: "The validate action worked!"

```bash
# Check codesign
codesign -dv --verbose=2 dist/Contextify.dmg 2>&1 | grep -E "Authority|Signature"
```
- [ ] Shows "Developer ID Application" authority
- [ ] Signature is valid

### 1B. DMG Mount and Contents

```bash
open dist/Contextify.dmg
```

- [ ] DMG mounts without Gatekeeper warning
- [ ] DMG shows Contextify.app and Applications folder shortcut
- [ ] DMG background image displays correctly

### 1C. App Gatekeeper Verification

```bash
# Before copying to Applications, verify the app inside the DMG
spctl -a -vvv --type exec "/Volumes/Contextify/Contextify.app"
```
- [ ] Output: "accepted" (source=Notarized Developer ID)

```bash
# Verify app signature
codesign --verify --deep --strict -vv "/Volumes/Contextify/Contextify.app" 2>&1
```
- [ ] "valid on disk"
- [ ] "satisfies its Designated Requirement"

### 1D. App Installation

```bash
cp -R "/Volumes/Contextify/Contextify.app" /Applications/
hdiutil detach "/Volumes/Contextify" 2>/dev/null
```

- [ ] App copies to /Applications without error
- [ ] App icon appears in Applications folder

### 1E. First Launch

```bash
open /Applications/Contextify.app
```

- [ ] App launches without Gatekeeper warning (notarized + stapled)
- [ ] No crash on launch
- [ ] HUD window appears
- [ ] App connects to existing database (if present)
- [ ] Menu bar shows Contextify menu

### 1F. App Version Verification

- [ ] About dialog shows version 1.3.0
  - Contextify menu > About Contextify

### 1G. Core App Functionality (Smoke Test)

- [ ] Timeline view loads conversations
- [ ] Search works (type a query, results appear)
- [ ] Project selector shows available projects
- [ ] App does not crash during normal use

### 1H. CLI Installation from DMG App

Navigate to Settings > CLI (or use menu: Contextify > Install Command Line Tool)

- [ ] "Install CLI" button is visible
- [ ] Clicking "Install CLI" prompts for admin password
- [ ] Installation completes without error

**After installing, open a NEW terminal:**

```bash
# Binary exists
which contextify
```
- [ ] `contextify` is found in PATH

```bash
# Version check
contextify --version
```
- [ ] Output: `contextify 1.3.0`

```bash
# Binary type (not a symlink)
file "$(which contextify)"
```
- [ ] Output contains `Mach-O`

```bash
# Symlinks exist
ls -la "$(which contextify-query)" "$(which contextify-ingest)"
```
- [ ] `contextify-query` exists
- [ ] `contextify-ingest` exists

```bash
# Symlinks point to contextify
readlink "$(which contextify-query)"
readlink "$(which contextify-ingest)"
```
- [ ] Both resolve to `contextify`

```bash
# Functional test
contextify status
```
- [ ] Shows database path
- [ ] Shows schema version
- [ ] Shows project/transcript counts

```bash
# Deprecation warning
contextify-query --version
```
- [ ] Shows deprecation warning about using `contextify` instead
- [ ] Still outputs version info
