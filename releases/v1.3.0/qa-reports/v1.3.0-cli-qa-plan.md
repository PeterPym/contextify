# v1.3.0 CLI Installation QA Plan

## Overview

Test clean installation of `contextify` CLI via both distribution methods:
1. **DMG** - CLI installed by app's "Install CLI" feature
2. **Homebrew** - CLI installed via `brew install` (also covers App Store users)

---

## Environment Sanitization

### What Gets Removed
- CLI binaries: `contextify`, `contextify-query`, `contextify-ingest`
- Symlinks to above
- Homebrew formula and cache
- App installations (`/Applications/Contextify.app`)

### What Gets Preserved
- **Databases are NOT removed** - they live at `~/Library/Application Support/Contextify/`
- If database removal is ever needed, backup first to `~/Desktop/contextify-db-backup-$(date +%Y%m%d)/`

### Sanitization Script

```bash
#!/bin/bash
set -e

echo "=== v1.3.0 CLI QA: Environment Sanitization ==="
echo "Date: $(date)"
echo ""

# Safety: Check for databases and confirm preservation
DB_PATH="$HOME/Library/Application Support/Contextify"
if [[ -d "$DB_PATH" ]]; then
    echo "Database directory exists: $DB_PATH"
    echo "  Size: $(du -sh "$DB_PATH" | cut -f1)"
    echo "  PRESERVING (not removing)"
    echo ""
fi

# 1. Quit Contextify app if running
echo "Step 1: Quit Contextify app..."
osascript -e 'quit app "Contextify"' 2>/dev/null || true
sleep 1

# 2. Remove app from Applications
echo "Step 2: Remove /Applications/Contextify.app..."
if [[ -d "/Applications/Contextify.app" ]]; then
    rm -rf "/Applications/Contextify.app"
    echo "  Removed"
else
    echo "  Not present"
fi

# 3. Remove CLI binaries from common locations
echo "Step 3: Remove CLI binaries..."
LOCATIONS=(
    "/usr/local/bin/contextify"
    "/usr/local/bin/contextify-query"
    "/usr/local/bin/contextify-ingest"
    "$HOME/bin/contextify"
    "$HOME/bin/contextify-query"
    "$HOME/bin/contextify-ingest"
    "$HOME/.local/bin/contextify"
    "$HOME/.local/bin/contextify-query"
    "$HOME/.local/bin/contextify-ingest"
)
for loc in "${LOCATIONS[@]}"; do
    if [[ -e "$loc" || -L "$loc" ]]; then
        sudo rm -f "$loc" 2>/dev/null || rm -f "$loc"
        echo "  Removed: $loc"
    fi
done

# 4. Uninstall Homebrew formula
echo "Step 4: Uninstall Homebrew formula..."
if brew list contextify-query &>/dev/null; then
    brew uninstall contextify-query
    echo "  Uninstalled contextify-query"
else
    echo "  Not installed via Homebrew"
fi

# 5. Untap Homebrew tap
echo "Step 5: Untap peterpym/contextify..."
if brew tap | grep -q "peterpym/contextify"; then
    brew untap peterpym/contextify
    echo "  Untapped"
else
    echo "  Not tapped"
fi

# 6. Clear Homebrew cache
echo "Step 6: Clear Homebrew cache..."
rm -rf "$(brew --cache)/downloads/"*contextify* 2>/dev/null || true
rm -rf "$(brew --cache)/Cask/"*contextify* 2>/dev/null || true
echo "  Cache cleared"

# 7. Remove installed skills/plugins
echo "Step 7: Remove installed skills/plugins..."
rm -rf "$HOME/.claude/skills/total-recall" 2>/dev/null || true
rm -rf "$HOME/.codex/skills/total-recall" 2>/dev/null || true
echo "  Skills removed"

# 8. Verify clean state
echo ""
echo "=== Verification ==="
CLEAN=true

for cmd in contextify contextify-query contextify-ingest; do
    if which "$cmd" &>/dev/null; then
        echo "WARNING: $cmd still found at $(which $cmd)"
        CLEAN=false
    else
        echo "OK: $cmd not found"
    fi
done

if [[ -d "/Applications/Contextify.app" ]]; then
    echo "WARNING: Contextify.app still present"
    CLEAN=false
else
    echo "OK: Contextify.app removed"
fi

echo ""
if $CLEAN; then
    echo "Environment is CLEAN - ready for QA testing"
else
    echo "WARNING: Environment not fully clean - manual intervention needed"
    exit 1
fi
```

## Test 1: DMG Installation (Production)

### Prerequisites
- Environment sanitized (run script above)
- Production DMG: `dist/Contextify.dmg`

### Steps

1. **Mount and install DMG**
   ```bash
   open dist/Contextify.dmg
   # Wait for mount
   sleep 3
   # Copy to Applications
   cp -R "/Volumes/Contextify/Contextify.app" /Applications/
   # Eject
   hdiutil detach "/Volumes/Contextify"
   ```

2. **Launch app and install CLI**
   ```bash
   open /Applications/Contextify.app
   # Wait for app to launch
   sleep 5
   # The CLI install requires user interaction (admin password)
   # OR use the app's CLI coordinator programmatically if available
   ```

3. **Restart shell and verify**
   ```bash
   exec $SHELL
   # Run verification
   ```

### Verification Checklist
- [ ] `contextify` binary exists and is executable
- [ ] `contextify --version` returns `contextify 1.3.0`
- [ ] `contextify-query` is a symlink to `contextify`
- [ ] `contextify-ingest` is a symlink to `contextify`
- [ ] `contextify status` connects to database
- [ ] `contextify-query --version` shows deprecation warning (in TTY)

## Test 2: Homebrew Installation (Production)

### Prerequisites
- Environment sanitized (run script above)
- Homebrew formula pushed to `peterpym/homebrew-contextify`

### Steps

```bash
# 1. Tap repository
brew tap peterpym/contextify

# 2. Install formula
brew install contextify-query

# 3. Verify
contextify --version
```

### Verification Checklist
- [ ] `contextify` installed at `$(brew --prefix)/bin/contextify`
- [ ] `contextify --version` returns `contextify 1.3.0`
- [ ] `contextify-query` is a symlink to `contextify`
- [ ] `contextify-ingest` is a symlink to `contextify`
- [ ] Plugin files exist at `$(brew --prefix)/share/contextify-query/claude-plugin/`
- [ ] User skill exists at `$(brew --prefix)/share/contextify-query/user-skill/total-recall/`
- [ ] `contextify install-plugin` works

## Evidence Requirements

For each test, capture:
1. **Pre-test state**: Output of `which contextify contextify-query contextify-ingest`
2. **Installation method**: Exact commands run
3. **Binary locations**: `ls -la $(which contextify) $(which contextify-query) $(which contextify-ingest)`
4. **Version output**: `contextify --version`
5. **File type verification**: `file $(which contextify)` (should be Mach-O, not symlink)
6. **Symlink verification**: `readlink $(which contextify-query)` (should point to contextify)
7. **Functional test**: `contextify status` output

## Database Backup Procedure (If Needed)

Only if database removal becomes necessary:

```bash
DB_PATH="$HOME/Library/Application Support/Contextify"
BACKUP_DIR="$HOME/Desktop/contextify-db-backup-$(date +%Y%m%d-%H%M%S)"

if [[ -d "$DB_PATH" ]]; then
    mkdir -p "$BACKUP_DIR"
    cp -R "$DB_PATH" "$BACKUP_DIR/"
    echo "Database backed up to: $BACKUP_DIR"
    ls -la "$BACKUP_DIR"
fi
```
