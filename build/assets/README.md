# Build Assets

Long-term asset library for Contextify. Not tied to specific launches or campaigns.

**Master catalog:** `build/ASSETS.md` - searchable index of ALL project assets (App Store, website, promo, brand)

## Structure

```
build/assets/
├── screenshots/     # Promotional screenshots for social, docs, blogs
└── README.md        # This file
```

## Other Asset Locations

| Location | Purpose |
|----------|---------|
| `website/assets/img/` | Production website images (optimized, WebP variants) |
| `appstore-metadata/screenshots/` | App Store screenshots (strict size requirements) |
| `build/design/brand/` | Brand assets (colors, icons, badges) |

## Adding Assets

See `build/ASSETS.md` for conventions and instructions.
