# Competitive Design Research: Dev Tool Websites

Reference sites for contextify.sh design direction. All are macOS/dev apps with clean, focused landing pages.

---

## 1. DevUtils - "indie dev toolbox" energy

**URL:** https://devutils.com

**Why it works:**
- Tight, clear hero with big headline ("All-in-one Toolbox for Developers")
- Single primary CTA: "Download for macOS" plus Homebrew snippet
- Single-column story: feature blocks, GIFs/screenshots, FAQ, pricing
- Tone: native macOS, dev audience, local-first/privacy angle

**Steal for Contextify:**
- Hero layout with download area (including `brew install contextify` if applicable)
- "Local, offline" trust signal copy
- Long scrollable one-pager: Hero → Features → Screenshots → FAQ → Pricing

---

## 2. OrbStack - serious dev infra, still lean

**URL:** https://orbstack.dev

**Why it works:**
- Focused hero: pain point → simple solution
- Disciplined content with simple nav (Pricing / Blog / Docs / Download)
- Good "dev-cred" touches: macOS version support, Homebrew snippet, licensing clarity

**Steal for Contextify:**
- Hero copy pattern: "[X pain] → [simple, fast alternative]"
- Prominent OS/version support + licensing blurb near CTA
- Simple top nav: Features · Docs · Pricing · Download

---

## 3. CleanShot X - polished single-product mac app

**URL:** https://cleanshot.com

**Why it works:**
- Screenshot-driven hero showing the app in action
- Feature banding: horizontal sections with icon+text rows
- Social proof: real testimonials with short quotes and avatars

**Steal for Contextify:**
- Replace placeholder hero with actual screenshot in Mac-window frame
- 3-4 CleanShot-style feature cards
- Real quotes from early users (eventually)

---

## 4. Raycast - dev app framing (larger scale)

**URL:** https://www.raycast.com

**Why it works:**
- Hero nails it in one line: "Your shortcut to everything"
- Strong platform/OS section with multiple download options
- Clean extension of the single-product pattern at larger scale

**Steal for Contextify:**
- Tagline structure: "Your AI coding sessions, finally searchable."
- Supporting line explaining *how* it works
- Multi-download CTA pattern (DMG + App Store + Homebrew)

---

## Common Patterns

All four sites share:

1. **One clear product** (not services/agency)
2. **Single hero + strong screenshot** above the fold
3. **One or two CTAs** (Download / Learn more / Pricing)
4. **Section structure:**
   - What it is
   - Who it's for
   - How it works
   - Features
   - Pricing
   - FAQ / docs
5. **No generic marketing filler**
