# Design Research

Competitive analysis, inspiration, and design explorations.

## Directory Structure

```
build/design/research/
├── README.md           # This file
├── competitive/        # Competitive analysis
├── inspiration/        # Visual references
└── ux/                 # UX research and flows
```

## Workflow

1. Research and exploration goes here (transient)
2. Finalized decisions graduate to parent directories:
   - Brand decisions → `build/design/brand/`
   - Website decisions → `build/design/website/`
   - Marketing decisions → `build/design/marketing/`

## To Add Research

Create markdown files in appropriate subdirectory:
- `competitive/` - Analysis of other products (1Password, Raycast, Bear, etc.)
- `inspiration/` - Visual references, screenshots, mood boards
- `ux/` - UX research, user flows, onboarding explorations
