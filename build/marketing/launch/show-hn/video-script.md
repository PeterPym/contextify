# Demo Video Script

Target length: 2-3 minutes

---

## Opening (25-30 sec)

> Before Claude Code, I was doing AI-assisted programming through ChatGPT's web interface. I'd built an open source tool called FileKitty for context curation - selecting and combining files to paste into chat. That hit the front page of HN. One thing I relied on was ChatGPT's sidebar to search back through old conversations.
>
> When I switched to Claude Code, I noticed two things: there's no searchable history, and by default, your conversations get deleted after 30 days. That felt wrong - this is valuable context just disappearing.
>
> Then I started splitting work between Claude Code and Codex when I'd burn through rate limits, and piecing together what I'd done across both became a mess.
>
> So I built Contextify. It watches both tools, summarizes conversations in real-time, and keeps everything in one searchable database.

## Recording Notes

- **Format**: Screen recording with picture-in-picture of yourself
- **Audio**: AirPods mic (test levels beforehand)
- **Visible elements**: Contextify HUD, terminal with Claude Code, your face
- **Style**: Casual, developer-to-developer, not marketing
- **Don't**: Say "hey everyone" or throat-clear at the start - just begin
