# Demo Video Script v2 (Re-record)

Target: 2-3 minutes
Setup: Screen recording ON, camera ON, Contextify running, Claude Code open

---

## Shot List

### 1. INTRO (30 sec)
**Show:** Contextify HUD visible in corner, terminal with Claude Code

> Before Claude Code, I was using ChatGPT's web interface with a tool I built called FileKitty for context curation - that hit the front page of HN.
>
> One thing I relied on was the search sidebar to find stuff in old conversations.
>
> When I switched to Claude Code, I noticed there's no searchable history, and by default your conversations get deleted after 30 days. Then I started splitting work between Claude Code and Codex when I'd hit rate limits, and piecing together what I'd done became a mess.
>
> So I built Contextify - an ambient flow monitor for CLI AI coding sessions.

---

### 2. WHAT IT DOES (20 sec)
**Show:** Point to HUD, scroll timeline, click an entry

> It watches both Claude Code and Codex, summarizes your conversations in real time, and keeps everything in one searchable database.
>
> Each entry here is a chunk of the conversation, summarized so you can skim it. Click to see the full message.

---

### 3. APPLE INTELLIGENCE (15 sec)
**Show:** Summary appearing/updating (hourglass → text)

> The summaries use Apple Intelligence - it's built into macOS Tahoe. Works completely locally, no API calls, no data leaving your machine.

---

### 4. SEARCH DEMO (20 sec)
**Show:** Type in search, hit enter, show results, Cmd+Enter to open search window

> Everything's searchable. Type a keyword, hit enter for quick results, or Cmd+Enter to open the full search window across all your projects.

---

### 5. MULTI-PROJECT (15 sec)
**Show:** Click between projects in sidebar, show unread badge

> It tracks every project separately. You can see unread counts - useful when you've got multiple things going, spinning plates across different repos.

---

### 6. PRIVACY (15 sec)
**Show:** Can just talk to camera here, or show Little Snitch blocking

> Your transcripts never leave your machine. Run Little Snitch, block all network requests - the app works exactly the same. I started my career at a privacy startup, this matters to me.

---

### 7. WRAP (15 sec)
**Show:** App in corner, look at camera

> That's Contextify. Native macOS app, free to download. There's an App Store version and a DMG if you want to skip the sandbox.
>
> Link's in the post.
