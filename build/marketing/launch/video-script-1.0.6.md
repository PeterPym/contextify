# Demo Video Script - v1.0.6 "What's New"

**Target Duration:** 60 seconds
**Purpose:** Quick feature announcement for social media
**Format:** Screen recording with voiceover (no face cam needed)

---

## Pre-flight Checklist

- [ ] Contextify running with some conversation history
- [ ] Claude Code terminal open
- [ ] Screen recording software ready (OBS, QuickTime)
- [ ] Microphone tested
- [ ] Total Recall CLI installed (Settings > CLI)

---

## Script

### OPENER (0-10s)
**Show:** Contextify HUD in corner, Claude Code terminal

> Contextify keeps a searchable record of your Claude Code sessions. Here's what's new in 1.0.6.

---

### FEATURE 1: macOS 15 SUPPORT (10-25s)
**Show:** Settings or About showing version, then timeline with entries

> First, the big one: macOS 15 support.
>
> You no longer need Tahoe. Timeline, search, and backup all work on Sequoia.
>
> AI summaries still need macOS 26, but you can start building your history now and get summaries when you upgrade.

---

### FEATURE 2: TOTAL RECALL (25-45s)
**Show:** Claude Code terminal, type a question, show it querying history

> Second: Total Recall. Your AI can now search your conversation history.
>
> [Type in Claude Code: "What did we decide about the database schema?"]
>
> It uses a new CLI to query your past sessions. Find decisions, solutions, anything you've discussed before.
>
> Install it from Settings, CLI tab.

---

### FEATURE 3: SIDECHAIN CAPTURE (45-55s)
**Show:** Timeline with agent/sidechain decorations visible

> Third: Better agent sidechain capture.
>
> When Claude spawns sub-agents, those conversations now show in your timeline with visual indicators.
>
> See the full picture of multi-agent work.

---

### OUTRO (55-60s)
**Show:** Download page or website

> Download free at contextify.sh. Your data stays on your Mac.

---

## Total: ~60 seconds

---

## Recording Tips

1. **Keep it tight** - Each section should feel snappy, not lingering
2. **Show, don't tell** - Let the visuals do the work where possible
3. **Natural pace** - Don't rush, but don't dawdle
4. **One take per section** - Record each section separately, edit together
5. **Background noise** - Record in a quiet space, or use noise reduction in post
