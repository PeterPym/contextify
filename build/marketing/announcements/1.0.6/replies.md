## Reply to u/quinncom (Reddit r/MacApps)

**Original thread:** https://www.reddit.com/r/macapps/comments/1pjb7dh/
**Original comment:** "I would love to try this - but it looks like it requires macOS 26? I'm gonna try to stay on macOS Sequoia as long as possible to avoid the liquid ass. :("

### Reply

Hey, following up on this - good news!

Contextify 1.0.6 now supports macOS 15 (Sequoia) in Lite Mode.

Timeline monitoring, search, and transcript backup all work fully. AI summaries are disabled since they require Apple Intelligence (macOS 26+), but you can:

1. Start building your searchable history now
2. Get summaries automatically when you eventually upgrade

Based on your use case (freelancer, multiple clients, filtering by project), this should work well - each project gets its own tab based on directory path, and full-text search works across all your sessions within a project.

Let me know if you try it!
