## Thread

### 1/5

Contextify 1.0.6 is out.

The big one: macOS 15 (Sequoia) support.

Timeline monitoring, search, and transcript backup now work on Sequoia. No need to upgrade to Tahoe.

AI summaries still require macOS 26, but you can start building your searchable history today.

---

### 2/5

New feature: Total Recall

Your AI can now search your conversation history.

"What did we decide about authentication last week?"
"Find where we discussed the database migration"

Install the CLI (Settings > CLI) and Claude Code gets a new skill to query your past sessions.

---

### 3/5

Improved agent sidechain capture

When Claude Code spawns sub-agents (Task tool, etc.), those conversations now appear in your timeline with visual indicators.

See the full picture of multi-agent work, not just the main thread.

---

### 4/5

Why this matters:

Claude Code auto-deletes your history after 30 days.
Contextify keeps it forever, searchable, private.

Now you can start on Sequoia and get summaries when you upgrade.
