## 30-Second Health Check

```bash
LOG="/tmp/transcript-queue-monitor-*.log"  # Generated by ../../scripts/logging/monitor-transcript-queues.sh

# All should return >0
grep -c "HOOVER-START" $LOG
grep -c "HOOVER-DONE" $LOG
grep -c "TIMELINE-LOAD" $LOG
grep -c "TIMELINE-APPEND" $LOG

# These should match
echo "Starts: $(grep -c HOOVER-START $LOG) = Dones: $(grep -c HOOVER-DONE $LOG)"
```

**Pass:** All >0, Starts = Dones
**Fail:** Any 0, or Starts ≠ Dones

## Essential Tags

| Tag | What It Means | Validate |
|-----|---------------|----------|
| `DISCOVERY-ORDER` | Projects sorted newest first | `grep "DISCOVERY-ORDER" $LOG \| head -1` |
| `HOOVER-START` | Hoovering begins | Count should = HOOVER-DONE |
| `HOOVER-DONE` | Hoovering completes | Count should = HOOVER-START |
| `HOOVER-SKIP-LARGE` | Large line skipped (>50KB) | Normal for Edit/Read results |
| `HOOVER-BATCH-INSERT-DONE` | DB batch written | Check duration (<5s) |
| `TIMELINE-LOAD` | Timeline querying DB | Should be >0 |
| `TIMELINE-APPEND` | Timeline updating UI | Should be >0 |
| `TIMELINE-SKIP` | Skip optimization active | Should be 0 (after fix) |

### Optional Hoover Loop Tracing

The noisy `[HOOVER-OUTER-LOOP]`, `[HOOVER-INNER-*]`, and `[HOOVER-READ-CHUNK]` tags are now gated behind an env var. To re-enable them while debugging ingest loops:

```bash
CONTEXTIFY_TRACE_HOOVER_LOOPS=1 scripts/xc.sh dr
```

Release builds ignore the flag; Debug builds default to **off** to keep captures readable.

## Common Diagnostics

### Find Hung Transcripts
```bash
comm -23 <(grep HOOVER-START $LOG | awk '{print $NF}' | sort) \
         <(grep HOOVER-DONE $LOG | awk '{print $NF}' | sort)
```

### Check Timeline Refresh Bug
```bash
grep "TIMELINE-SKIP.*unchanged" $LOG | wc -l  # Should be 0 (after fix)
grep "TIMELINE-SKIP-DISABLED" $LOG | wc -l    # Should be >0 (after fix)
```

### Track Specific Transcript
```bash
ID="7DEF49DE-4F9D-4D8A-AE6C-3BAF4E357749"
grep "$ID" $LOG | grep -E "HOOVER|TIMELINE|DB-UPDATE"
```

### Measure Performance
```bash
grep "HOOVER-DONE.*in.*ms" $LOG | grep -o "[0-9]*ms" | sort -n | tail -5
```

## Decision Tree

```
Timeline not showing entries?
├─ HOOVER-DONE count = 0?
│  └─ YES → Hoovering not running (check HOOVER-START)
│  └─ NO  → Continue
├─ TIMELINE-LOAD count = 0?
│  └─ YES → Timeline not monitoring
│  └─ NO  → Continue
├─ TIMELINE-APPEND count = 0?
│  └─ YES → UI not updating
│  └─ NO  → Continue
└─ TIMELINE-SKIP count > 10?
   └─ YES → Skip bug (our fix addresses this)
   └─ NO  → Check database entries directly
```

---

## Pipeline Stages

**Complete pipeline:** Discovery → Hoover → Database → Timeline → UI

**Validation:**
1. `DISCOVERY-ORDER` present?
2. `HOOVER-START` = `HOOVER-DONE`?
3. `DB-UPDATE` present?
4. `TIMELINE-LOAD` present?
5. `TIMELINE-APPEND` present?

**Break point:** First NO = where pipeline is broken

## Thresholds

| Metric | Normal | Warning | Critical |
|--------|--------|---------|----------|
| Hoover completion % | 100% | 95-99% | <95% |
| Batch insert time | <500ms | 500ms-5s | >5s |
| Timeline load time | <100ms | 100-500ms | >500ms |
| Skip count (after fix) | 0 | 0 | >0 |
