Contextify

AI Session Manager for macOS

Welcome to Contextify

Contextify is a macOS application that helps you manage and navigate your Claude Code and Codex CLI sessions with powerful features including real-time timeline summaries, multi-project support, and intelligent search.

Key Features

📊 Timeline View

Real-time conversation summaries powered by Apple Intelligence

🗂️ Multi-Project

Manage multiple projects with drag-and-drop tab ordering

🔍 Transcript Search

Browse and search all your AI conversation history

📝 Session Metadata

Automatic titles, descriptions, and topic tagging

Getting Started

Setting Your Project Root

  1. Launch Contextify
  2. Click "Set Project Root" in the main window
  3. Select your project directory
  4. Contextify will automatically discover transcripts from:
    • ~/.claude/projects/ (Claude Code)
    • <project>/.codex/sessions/ (Codex CLI)

Project Management

  • Switch Projects: Click tabs at the top or use ⌘⇧[ / ⌘⇧]
  • Reorder Tabs: Drag and drop project tabs to your preferred order
  • Hide Projects: Right-click a tab → "Hide from Tabs"
  • View All Projects: ⌘⇧P opens the Projects window

Transcript Inventory

  • Open with ⌘⌃I or Window → Show Transcript Inventory
  • Browse all sessions across all projects
  • Click any session to load it in the timeline
  • Delete old sessions or cleanup missing transcripts

Keyboard Shortcuts

Action Shortcut
Next Project ⌘⇧]
Previous Project ⌘⇧[
Open Projects Window ⌘⇧P
Open Transcript Inventory ⌘⌃I

Timeline Features

  • Auto-Summaries: Each conversation turn gets a present and past tense summary
  • Session Filtering: Click session IDs to filter timeline by specific conversations
  • Live Updates: Timeline automatically updates as you work in Claude Code or Codex
  • Status Bar: Shows LLM processing status and queue information at the bottom

Database & Storage

Contextify stores all data locally in:

  • ~/Library/Application Support/Contextify/contextify.db
  • SQLite database with WAL mode for concurrent access
  • No cloud sync - all data stays on your Mac

Database Management

Use the included scripts for maintenance:

  • make clean-db - Clean database (creates backup first)
  • make db-backup - Create manual backup
  • make db-restore - Restore latest backup

Requirements

  • macOS 15.6+ (some features require macOS 26.0+)
  • Apple Silicon or Intel Mac
  • Claude Code or Codex CLI for transcript generation
  • Apple Intelligence (optional) - for LLM-powered summaries on macOS 26.0+

Troubleshooting

Timeline Not Updating

  • Check that transcripts exist in ~/.claude/projects/
  • Verify file system permissions for the transcript directories
  • Try manually refreshing in the Transcript Inventory

LLM Processing Stuck

  • Check status bar for error messages
  • On macOS < 26.0, LLM features fall back to heuristics
  • Circuit breaker activates after repeated failures (auto-recovers)

Projects Not Appearing

  • Open Projects window (⌘⇧P) and click Refresh
  • Check for hidden projects (context menu → "Restore All Hidden Tabs")
  • Verify project directory exists and has transcripts
