Contextify 1.3.2

Performance Hotfix

  • Fixed search hanging on OR queries - Resolved a critical regression where CLI searches with multiple terms could hang for minutes.
  • 85x faster search - Cold cache searches improved from 74s to under 1 second.
  • Term counts now opt-in - Per-term match counts available via --term-counts flag instead of running automatically.
  • Optimized searchCount with FTS-only fast path.
  • Fixed SQLite query plan inversion that bypassed FTS index.
