What's New

  • Total Recall Expanded - Now supports Codex CLI and git worktrees
  • Inline Images - Images render inline with Quick Look preview
  • Markdown Tables - Tables in conversation details now render nicely
  • Faster Imports - 2.5x faster bulk transcript ingestion

  • Codex CLI Support - Total Recall now works with OpenAI's Codex CLI alongside Claude Code. Search across all your conversations regardless of provider.
  • Git Worktree Search - Search conversations across all related worktrees in one request. Built something in worktree B last month? Find it from any worktree.
  • CLI Health Checker - New contextify-query doctor command diagnoses installation issues

Bug Fixes

  • Project misattribution from session ID collisions
  • Sidechain filter now independent of "show hidden" setting
  • PATH warning during CLI installation

Alpha: Linux CLI

  • Total Recall for Linux - Search your Claude Code and Codex CLI conversation history via contextify-query
