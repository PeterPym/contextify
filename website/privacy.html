Privacy Policy

Contextify for macOS

Effective Date: November 11, 2025

Introduction

Contextify is a macOS application designed to help you monitor and manage your Claude Code and Codex CLI sessions. Your privacy is important to us. This Privacy Policy explains how Contextify handles your data.

Data Collection

We do not collect any personal data.

Contextify operates entirely locally on your Mac. All data processing happens on your device, and no information is transmitted to external servers.

Local Data Storage

Contextify stores the following data locally on your Mac:

  • Transcript Data: Copies of your Claude Code and Codex CLI conversation transcripts
  • Generated Summaries: LLM-generated summaries of conversation entries (when using macOS 26+)
  • Project Metadata: Project names, file paths, and session timestamps
  • Application Preferences: User settings and configurations

All data is stored in:

  • ~/Library/Application Support/Contextify/ (default location)
  • Custom location (if configured by user)

Data Processing

When using macOS 26 (Sequoia) or later, Contextify uses Apple's on-device LanguageModel APIs to generate conversation summaries. This processing:

  • Happens entirely on your device
  • Does not send data to external servers
  • Uses Apple's private, on-device machine learning models
  • Is subject to Apple's privacy protections

Third-Party Services

Contextify does not use any third-party services, analytics, tracking, or cloud storage.

Data Sharing

We do not share, sell, or transmit any of your data. All data remains on your Mac under your control.

Data Retention

You control all data retention. Data remains on your Mac until you:

  • Delete the database manually
  • Uninstall the application
  • Delete specific projects or sessions

Your Rights

Since all data is stored locally on your Mac, you have complete control:

  • Access: View all data through the application or directly in the database
  • Deletion: Delete any or all data at any time
  • Export: Access the SQLite database directly for export
  • Portability: Move the database to another location or machine

Security

Your data security is ensured through:

  • Local-only storage (no network transmission)
  • macOS file system permissions
  • Optional custom database locations (e.g., encrypted volumes)
  • Standard macOS application sandboxing (when distributed via App Store)

Children's Privacy

Contextify is not directed to children under 13. We do not knowingly collect data from children, as we do not collect any data at all.

Changes to This Policy

We may update this Privacy Policy from time to time. Changes will be posted on this page with an updated effective date. Continued use of Contextify after changes indicates acceptance of the updated policy.

Consent
