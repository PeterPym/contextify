Contextify

Monitor your Claude Code and Codex CLI sessions on macOS

What it does

  • Real-time timeline of your AI coding sessions
  • Local database backup of all conversations
  • LLM-generated summaries using macOS on-device intelligence
  • Project-centric view across multiple sessions
  • Transcript repair tool for corrupted Claude Code Web sessions

Download

Coming soon to the Mac App Store.

System Requirements

  • macOS 14 (Sonoma) or later
  • macOS 26 (Sequoia) required for LLM summaries
  • Works with Claude Code and Codex CLI

Features

Project Discovery

Automatically discovers Claude Code and Codex projects on your Mac. Switch between projects with a single click.

Timeline View

See a chronological view of all messages in your AI sessions. Each entry includes a summary generated by macOS's on-device LLM (Sequoia only).

Local Storage

All data stored locally in a SQLite database. No cloud services, no tracking, no analytics. Your conversations stay on your Mac.

Transcript Repair

Built-in tool to detect and repair corrupted Claude Code Web transcripts that cause API 400 errors when resuming sessions.
