Get started in 3 steps

1
Install the CLI

If you have not already installed the Contextify CLI, run this in your terminal. It works on both macOS and Linux.

$ curl -fsSL https://contextify.sh/install.sh | sh
2
Configure cloud sync

Run the setup command and paste your API key when prompted. This configures your machine for encrypted cloud sync.

$ contextify cloud setup
# Paste your API key when prompted
3
Start syncing

Push your existing transcripts to the cloud and pull down any sessions from your other machines.

$ contextify cloud sync
# Syncs transcripts across machines
