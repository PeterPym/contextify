Which Should I Choose?

Choose App Store if you...

  • Want hassle-free updates through the App Store
  • Use Family Sharing to share with family members
  • Prefer Apple's payment and refund process
  • Don't mind granting folder permissions on first run

Choose DMG if you...

  • Want the simplest first-run experience
  • Need live git branch display in the HUD
  • Prefer apps without sandbox restrictions
  • Are comfortable approving apps in Gatekeeper once
