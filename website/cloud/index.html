FAQ

Common questions

How is this different from Dropbox or iCloud sync?

Dropbox syncs files. Contextify Cloud syncs structured, parsed data: conversation entries, summaries, project metadata. It uses incremental cursor-based sync with server-side deduplication, handles the append-only nature of conversation logs efficiently, and provides search and analytics on top. Dropbox cannot do concurrent multi-device database access.

Can I use Contextify without Cloud?

Yes. Cloud sync is off by default. The macOS app and Linux CLI work fully offline with all core features: real-time timeline, search, LLM summaries. Many users run local-only permanently.

What data gets synced?

Conversation entries (prompts and responses), LLM summaries, project metadata, transcript metadata, tool invocations, and usage statistics. Raw JSONL transcript files, app settings, and Apple Intelligence processing state stay local. The sync payload is parsed structured data, not raw files.

Can I exclude specific projects from syncing?

Per-project sync controls are coming soon. Today, cloud sync operates at the account level. You can disable sync entirely at any time.

What happens if I stop paying?

Your local database is unaffected. See Pricing for current details on retention and account status after cancellation.

Is there a self-hosted option?

The cloud backend is FastAPI + PostgreSQL deployed via Docker Compose. Self-hosted documentation is planned for advanced and enterprise users. The managed service at cloud.contextify.sh is the supported path today.
