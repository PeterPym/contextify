How It Works

Local-first, cloud-optional

Contextify works entirely offline. Cloud sync is opt-in, and your local database is always the primary copy. The cloud adds backup, cross-device access, and team features on top.

1

Contextify watches locally

The macOS app and Linux CLI monitor your Claude Code and Codex sessions in real-time. Everything goes into your local SQLite database first.

2

Cloud sync pushes changes

When cloud sync is enabled, new entries are pushed to Contextify Cloud in small batches. The sync is incremental, cursor-based, and idempotent.

3

Access from anywhere

Pull your history to a second Mac, search from the web dashboard, or use the Linux CLI to query from a remote server. It all stays in sync.

Security

Built so we can't misuse your data, not just promising we won't

Security is an architectural property of Contextify Cloud, not a policy checkbox.

🔒

Off by default

Cloud sync ships disabled. You explicitly enable it per machine. Disable it at any time and your local database keeps working exactly as before.

🗃

Schema-per-tenant isolation

Each workspace gets its own PostgreSQL schema. Your queries physically cannot touch another customer's data. This is a database-level guarantee, not an application-level filter.

🌐

Encrypted in transit

All sync traffic uses TLS 1.2+ over HTTPS. Certificate management is automated via Let's Encrypt.

👤

API key authentication

Your sync connection uses a unique API key generated during setup. No passwords stored on the server, no third-party OAuth dependency.

💾

No cloud lock-in

Your local SQLite database is always the primary copy. If the cloud disappears tomorrow, you still have everything. Cloud is additive, not required.

🗑

Full deletion on request

Ask us to delete your cloud data and we drop the schema. No "30-day retention," no "anonymized analytics" carve-outs. Gone is gone.

  • We do not read your conversation content for training, analytics, or any purpose other than serving it back to you.
  • We do not share data across tenants.
  • We do not retain data after you delete your account.

Setup

1

Download Contextify

From contextify.sh/download (macOS) or install the Linux CLI.

2

Create a cloud account

Sign up at cloud.contextify.sh. You get an API key immediately.

3

Enable cloud sync

Open Settings > Cloud in the macOS app, or run contextify cloud setup on Linux. Paste your API key.

4

Sync starts automatically

Your existing history uploads first. After that, new entries sync incrementally every few minutes. Typical sync is a few KB.

FAQ

Common questions

How is this different from Dropbox or iCloud Drive sync?

Dropbox syncs files. Contextify Cloud syncs structured, parsed data (entries, summaries, metadata). It understands the content, so you can search by conversation text, filter by project, and see analytics. It also uses incremental cursor-based sync with server-side deduplication, so it handles the append-only nature of conversation logs efficiently. Dropbox cannot handle concurrent database access from multiple devices.

Can I use Contextify without Cloud?

Yes. Cloud sync is off by default. The macOS app and Linux CLI work fully offline with all core features: timeline monitoring, search, LLM summaries. Many users run Contextify in local-only mode permanently.

Does it work offline?

Yes. The local database is the primary copy. Cloud sync happens in the background when you have connectivity. If you are offline, the app works normally and syncs when the connection returns.

Does the cloud process my conversations with AI?

No. LLM summaries are generated locally on your Mac using Apple Intelligence. The cloud stores the summaries you sync, but it does not run any AI processing on your data.

Can I exclude specific projects from syncing?

Per-project sync controls are coming soon. For now, cloud sync operates at the account level. You can disable sync entirely at any time.

What happens if I stop paying?

Your local database is unaffected. Cloud data is retained for a grace period after cancellation, then deleted. You can export or pull your data before deletion.

Is there a self-hosted option?

The cloud backend is FastAPI + PostgreSQL, deployed via Docker Compose. Self-hosted documentation is planned for Enterprise plans. The managed service at cloud.contextify.sh is the current option.
