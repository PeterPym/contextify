What it is

Contextify is a macOS and Linux app that monitors your Claude Code and Codex sessions, indexing every conversation into a local database you can search. Cloud sync makes that database available on every machine you work on. Total Recall lets your current AI session search all of your past ones. Local-first, always. Cloud adds cross-device search, backup, and team features on top.
