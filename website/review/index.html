Contextify - App Store Review Materials

Thank you for reviewing Contextify. This page provides sample data and instructions for testing the app.

Download Sample Data

Download sample-data.zip (100 KB)

Setup Instructions

  1. Close Contextify if it is currently running
  2. Download and extract sample-data.zip
  3. Copy Claude Code transcripts to the Claude projects directory: 
    cp -r sample-transcripts/claude/projects/* ~/.claude/projects/
  4. (Optional) Copy Codex sessions: 
    cp -r sample-transcripts/codex/sessions/* ~/.codex/sessions/
  5. Launch Contextify
  6. The sample projects will appear in the project switcher:
    • taskflow - CLI task manager project
    • weatherly - Weather dashboard project
    • recipebox - Recipe manager project

Features to Test

  • Project Detection: Sample projects appear in the tab bar
  • Timeline View: Shows conversation history with user/assistant messages
  • LLM Summaries: Each entry displays an AI-generated summary (generated on-device)
  • Search: Cmd+F for quick search, Cmd+Shift+F for deep search
  • Project Switching: Click tabs to switch between projects
  • Real-time Updates: New conversations appear automatically

About the Sample Data

The sample data contains real Claude Code and Codex CLI transcript files from fictional software development projects:

  • TaskFlow: Building a CLI task manager in Python (2 sessions, 12 turns)
  • Weatherly: Building a weather dashboard with API integration (1 session, 7 turns)
  • RecipeBox: Building a recipe search feature (1 session, 7 turns)

These demonstrate the natural conversation flow that Contextify monitors and summarizes.

Note: Contextify requires access to ~/.claude/ to read Claude Code transcripts. A permission dialog will appear on first launch. The app reads transcript files but does not modify them.
